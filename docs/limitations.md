# 局限（Limitations）

> 纪律：**这份文件是报告的必填输入**。最终仓库里 `report.py` 会把它并入评测报告；缺失即视为构建失败。
> 一条不留地写出来，比让面试官问出来强。

---

## 1. 接入方式：经第三方聚合端点

三臂均经 **opencode 聚合端点**接入，而非各厂商官方 API。

**后果**：模型后端可能与官方不完全一致；同一 ID 的后端也可能随时间被替换（已有先例：官方确认 `deepseek-v4-flash` 的请求被路由到 DeepSeek-V4.1-Flash）。

**因此**：本项目结论**仅用于方法学演示**，不可用于模型选型决策。

**缓解措施**：记录每次调用的 `request_datetime`，跑批后对比前后半段准确率，作为"后端是否漂移"的粗检。

---

## 2. 无 logprob：放弃校准类指标

封闭 API 不提供可靠的 `logprobs`，tokenizer 也不公开。

**因此无法计算**：ECE 等校准指标、perplexity、accuracy@k、似然打分式的 MCQ。

**这是与 HELM 的一处硬性差异**——HELM 的 `compute_calibration_metrics` 与"每个选项单独打分"路径在本环境不可用。

---

## 3. 样本量与置信区间

评测集 **600 题**（含自建边界样本 50 题）。在 p≈0.5 时，单模型准确率的 **95% CI 宽度约 ±4pp**。

**因此**：
- 报告中**必须写出 CI 宽度**，不能只报点估计
- 排名差异在 4pp 以内时**统计上不显著**，不得硬解读为"模型 A 优于 B"
- C2 / C5 对照仅 150 题，CI 更宽（约 ±8pp），其 Δacc 结论须更保守

---

## 4. LLM-as-Judge 的争议

NeurIPS 2025 立场论文（*Neither Valid nor Reliable? Investigating the Use of LLMs as Judges*）指出 LLM judge 的采用「已超出对其可靠性/有效性的审慎检验」。

**因此**：本项目 **仅将 judge 用于判分复核的交叉验证（C4），不作为唯一判分依据**。客观 MCQ 有标准答案，规则判分在该场景可辩护。

---

## 5. 数据污染无法排除

无法确认三臂的训练语料是否包含 MMLU-ProX 或其同源数据。

**缓解**：自建 50 题边界样本（超多选项 / 强干扰项 / 否定式提问 / 长题干 / 答案位置偏置）作为抗污染构造的一部分；并做自建集与公开集的难度/选项数分布一致性检验。

**但**这只降低风险，不消除——**不宣称"无污染"**。

---

## 6. 范围裁剪（有意为之，非遗漏）

| 未做 | 理由 |
|---|---|
| **HELM 口径的 robustness**（typo / 对抗改写 / contrast sets） | 有意的范围裁剪。方向已从鲁棒性切到准确性；且中文扰动集构建依赖人工，与 8 天窗口冲突 |
| **多语言对照** | 跨语言在目标岗位 JD 覆盖仅 4/105，不值得占窗口 |
| **位置诊断（选项乱序）** | 近期系统实验显示 position bias 已降至 ≤0.04（跨 5 模型 4 厂商一致），测一个基本不存在的偏差 ROI 过低。已由自建集的"答案位置偏置"类别替代 |
| **开放生成 / 多模态 / 安全合规** | 项目定位为纯文本单轮 MCQ |
| **SQL 数据仓库** | 目标岗位 JD 覆盖仅 6/105 |

---

## 7. 判分口径的已知边界

- **严格 vs 宽松双解析**：两套口径的差值即"被格式吃掉的能力"，但**哪一套更"正确"没有客观标准**——本项目并列报告，不做单一裁决。
- **四档判级中的 `invalid`**：判据是"无法解析出有效选项"，边界情况（如输出含多个字母）依赖实现细节，已在 `tests/test_tally.py` 中固化用例。
- **归因类别**（事实性 / 推理链 / 选项混淆）：由本人人工标注 80–120 条，**存在主观性**；未计算标注者间一致性（单标注者）。

---

## 8. 工程层面的诚实声明

- **`temperature` 在本池子上弱生效甚至被忽略**（实测：temp=1.0 时同题 6 次仅产生 1–2 种输出）。因此"固定温度 = 可复现"**不成立**，C3 重复采样臂是唯一能量化确定性的手段。
- **`resp_model` 字段只是回显请求名**，不含后端信息，**不能用于别名检测**；本项目改用行为指纹。
- **免费 / 预览档可能限流或变更**：`longcat-2.5-preview-free` 与 `mimo-v2.6-flash` 均为免费档，跑批中途的限流或后端变更会影响数据可比性。
